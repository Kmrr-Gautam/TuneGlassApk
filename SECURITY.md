# Security Policy

## Supported Versions

Security fixes are provided for the latest stable release of TuneGlass.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability in TuneGlass, please report it privately rather than creating a public issue.

### How to Report
* Submit a private security advisory through the GitHub repository: https://github.com/Kmrr-Gautam/TuneGlassApk
* Include:
  * Description of the vulnerability
  * Affected versions and components
  * Steps to reproduce or proof-of-concept
  * Potential impact assessment

### Response Timeline
* **Initial acknowledgment:** Within 48 hours.
* **Assessment & mitigation plan:** Within 5 business days.
* **Public disclosure:** Coordinated after a patched release is published.

Thank you for helping keep TuneGlass secure for all users.
